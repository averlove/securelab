4. Висновки

У ході лабораторної роботи було усунуто критичну вразливість SQL-ін'єкції (S-01) шляхом переходу від сирого SQL-запиту `FromSqlRaw` з конкатенацією рядків до безпечного параметризованого LINQ-пошуку `EF.Functions.ILike` з буквальним екрануванням спецсимволів `EscapeLike`. Також реалізовано повний контракт серверної валідації вхідних даних, правила бізнес-логіки (T-03, T-09, T-10) та allowlist-сортування.
